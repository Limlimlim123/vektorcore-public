VektorCore

VektorCore 是一个正在开发中的在线卡片与标签设计工具。

项目目前处于 MVP 开发与内部测试阶段，尚未正式公开上线。

我正在持续开发和完善这个项目，当前主要围绕以下方向进行测试与验证：

- AI 辅助生成卡片与标签设计
- 可继续调整和编辑的设计结果
- 矢量文件与 PDF 导出
- 更适合实际设计与输出场景的工作流程

VektorCore 目前仍处于早期阶段，功能、交互和生成质量都在持续迭代中。

本仓库仅作为 VektorCore 的公开项目介绍与开发状态页面，不包含项目源码、内部架构、模型提示词或其他开发资料。
